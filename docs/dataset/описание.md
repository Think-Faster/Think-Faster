# Датасет кейса: состав и формат

Датасет организаторов ЛЦТ-2026: журнал событий системы мониторинга коллекторов за 2019 — 30.06.2026 и справочники к нему. Выгружен 15.09.2026, справочник каналов заменён обновлённым от 17.09.2026: в нём появилась связь канала с объектом и восстановлены 364 названия, где раньше топонимы были вырезаны (`Темп. ПК377 cопряж. с .` → `Темп. ПК377 cопряж. с Ломонос.`).

Первичный анализ — в [анализ.md](анализ.md), запросы для повторения — в [запросы.sql](запросы.sql).

**Почему журналов нет в git.** Каждый архив весит 135–277 МБ, а GitHub принимает файлы не больше 100 МБ. Бесплатная квота Git LFS — 1 ГБ, архивы в неё тоже не помещаются.

**Где взять журналы.** Ссылка организаторов на Яндекс Диск: <https://disk.yandex.ru/d/Os09EWI6VU093g>. Архив закрыт паролем — пароль у капитана или в чате команды. **В репозиторий пароль не записывать.**

## Как распаковать и загрузить

Архивы `.7z` внутри `dataset.zip`. Их распаковывает 7-Zip или Python-пакет `py7zr`.

> ⚠️ Имена файлов в zip записаны в кодировке cp866, поэтому кириллица может отображаться «кракозябрами». 7-Zip и Проводник Windows показывают их правильно.

Удобнее всего работать через [DuckDB](https://duckdb.org/): `pip install duckdb`. Он читает CSV напрямую, загрузка всех 8 журналов занимает около 40 секунд, база на диске — около 3,5 ГБ. Скрипт загрузки — в начале [запросы.sql](запросы.sql).

> Пути длиннее 260 символов на Windows ломают Python. Распаковывайте в короткую папку, например `C:\data\tf`.

### Годовые журналы и пример отличаются форматом

| | `ext-journal-ГГГГ.csv` | `журнал_событий_пример.csv` |
|---|---|---|
| Кавычки | нет | текстовые поля и даты в `"` |
| `тревожное` | `t` / `f` | `true` / `false` |
| Период | 01.01.2019 — 30.06.2026 | только 01.08.2026 — за пределами годовых файлов |

| Особенности | в `ext-journal-2025.csv` внутри файла повторяется строка заголовка | — |

Десятичный разделитель в журналах — **точка** (`0.16`). В примере из ТЗ (Приложение 1) — запятая: при интеграции проверять оба варианта.

### Тег

Формат `<префикс>-a.b.c.d.`, в конце всегда точка.

- **Префикс** — 32 значения: `847`, `914`, `257`, … Под одним префиксом от 1 до 1 459 каналов разных систем.
- У 92% тегов 4 сегмента после дефиса, у остальных 1, 3 или 5. Встречаются сегменты вида `g1.`.
- **Гипотеза:** префикс — контроллер или участок, третий сегмент — шлейф или линия, четвёртый — адрес устройства. Пример: `847-1.1.58.*` — дымовые извещатели ПК253–ПК276, `847-1.1.59.*` — ПК276–ПК302. **Как проверить на данных:** для каждого третьего сегмента собрать диапазон пикетов из названий каналов — если диапазоны не пересекаются и идут подряд, сегмент действительно означает участок.

## Справочник объектов

| Поле | Пример | Смысл |
|---|---|---|
| `ид_объект` | `5332` | ID объекта |
| `иерархия_уровень` | `3` | 1 — район, 2 — объект, 3 — часть объекта |
| `родитель` | `5327` | `ид_объект` родителя |
| `вид_объекта` | `guardObject` | `district`, `controlHouse`, `guardObject` |
| `диспетчерское_название_объекта` | `объект Кси ПК0-ПК202` | названия обезличены греческими буквами |

**Дерево:** 1 район (`5773`) → 16 объектов (`controlHouse`: Альфа, Бета, … Кси) → 78 частей: 49 `controlHouse` (ДП, ДУ, шкафы ОПС/ОС/ПС) и 29 `guardObject` (зоны ОС/ПС, участки по пикетам).

**Связь «канал → объект» есть с 17.09.2026.** В обновлённом справочнике каналов появилось поле `ид_объект`, оно заполнено у всех 11 485 каналов и всегда указывает на существующий объект. Каналы распределены по 78 объектам из 95; 17 объектов каналов не имеют — это район и объекты второго уровня, у которых датчики висят на частях. Самые крупные: `5677` объект Мю ПС — 994 канала, `3356` ПС объект Тау — 919, `5332` объект Кси ПК0-ПК202 — 842. Сопоставлять по пикетам вручную больше не нужно.

**Первый срез по объектам** (сутки примера, 01.08.2026): события были у 56 объектов из 78 — у 33 диспетчерских пунктов и 23 охранных зон. При этом 117 833 события из 169 993 (69%) дал один объект `5122` ДУ объект Альфа — там висят газовые датчики, опрашиваемые постоянно. Крупнейшие по числу каналов охранные зоны за эти сутки молчали: у `5677` объект Мю ПС с его 994 каналами нет ни одного события. Это тот же перекос, что виден по типам датчиков, но теперь его можно считать в разрезе объекта.
